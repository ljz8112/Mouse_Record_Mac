# 使用指南

本文档介绍 MouseRecorder 的常见操作流程和注意事项。

## 授予辅助功能权限

MouseRecorder 需要使用 macOS 辅助功能权限来监听和模拟鼠标事件。

1. 启动应用。
2. 根据应用提示打开系统设置。
3. 进入 `Privacy & Security > Accessibility`。
4. 勾选或添加 `MouseRecorder`。
5. 重新启动应用。

如果录制无法开始，或回放没有产生点击，优先检查这里的权限状态。

## 录制点击事件

1. 点击工具栏中的“开始录制”，或按 `Command + R`。
2. 应用会缩小为右上角悬浮迷你窗口。
3. 在目标应用中完成需要录制的点击。
4. 点击迷你窗口中的“停止录制”，或按 `Shift + Command + R`。

录制时会忽略落在 MouseRecorder 自己窗口上的点击，避免把停止按钮等操作写入事件列表。

## 编辑事件

每个事件包含以下字段：

- 名称：便于识别该步骤的用途
- 鼠标按键：左键、右键或中键
- X/Y 坐标：屏幕左上角为原点
- 触发前等待：执行该事件前等待的秒数

可以在事件列表中直接编辑这些字段，也可以选择事件后使用“修改坐标”打开坐标拾取器。

## 手动添加事件

点击工具栏的 `+`，填写事件名称、按键、坐标和延迟。坐标可以手动输入，也可以通过“拾取鼠标位置”在屏幕上选择。

## 回放事件

1. 确认目标窗口已经打开并处于正确状态。
2. 点击“回放”，或按 `Command + P`。
3. 应用会进入迷你窗口，并按列表顺序执行所有事件。
4. 如需中止，点击“停止回放”，或按 `Shift + Command + P`。

回放会真实点击屏幕坐标。建议先用无风险页面或测试数据验证事件列表。

## 定时运行

进入“定时运行”页面后，可以设置今天或明天的触发时间。若输入时间早于当前时间，应用会自动安排到明天。

偏移字段用于微调触发时间：

- `0 ms`：准时触发
- 正数：在设定时间之后触发
- 负数：在设定时间之前触发

## 导入与导出

通过“更多”菜单可以导出当前事件列表，也可以导入之前保存的 JSON 文件。导入时会重新生成事件 ID，避免和当前列表里的事件冲突。

示例文件位于 [../Examples/MouseRecorderEvents.sample.json](../Examples/MouseRecorderEvents.sample.json)。

## 常见问题

### 无法开始录制

请检查辅助功能权限，并确认当前运行的 app 已经被添加到 Accessibility 列表。

### 回放没有点击目标位置

请确认目标窗口位置、屏幕缩放、外接显示器布局和录制时保持一致。坐标基于屏幕左上角，窗口移动后可能需要重新拾取坐标。

### 定时任务没有触发

请确认应用仍在运行，且没有处于录制或回放状态。当前定时功能依赖应用进程内的计时器。

### 导入失败

请确认 JSON 文件是事件数组，并且 `button` 字段为 `Left`、`Right` 或 `Middle`。
